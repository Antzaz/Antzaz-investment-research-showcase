MODEL LOGIC

How the browser demo works

Revenue(t) = Revenue(t-1) × (1 + scenario revenue growth)

FCF(t) = Revenue(t) × scenario FCF margin

PV of FCF = FCF(t) / (1 + scenario WACC)^t

Terminal value = FCF(2035) × (1 + g) / (WACC − g)

Equity value = PV forecast FCF + PV terminal value + net cash

Value/share = Equity value / diluted shares

Reverse DCF = solve constant 10Y FCF CAGR such that value/share = market price

Important limitations

This remains a simplified educational/recruiter-facing demonstration. It intentionally does not reproduce the production workbook's full statements, company-specific segment extraction, source audit trail, live consensus, issuer guidance reconciliation, AI research layer, ownership/transaction research, scoring audit detail, private research journal or production data-quality gates. It is not an investment recommendation or a live price target.
