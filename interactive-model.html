MODEL LOGIC

How the browser model works

Revenue(t) = Revenue(t-1) × (1 + revenue growth)

FCF(t) = Revenue(t) × FCF margin

PV of FCF = FCF(t) / (1 + WACC)^t

Terminal value = FCF(2035) × (1 + g) / (WACC − g)

Equity value = PV forecast FCF + PV terminal value + net cash

Value/share = Equity value / diluted shares

Important limitations

This is a simplified educational/recruiter-facing DCF demonstration built from a static public-data snapshot. It is not a live price target, investment recommendation, or substitute for a full segment model, detailed stock-based compensation treatment, tax schedule, working-capital build, or issuer guidance reconciliation.
